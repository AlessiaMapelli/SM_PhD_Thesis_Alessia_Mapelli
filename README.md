# Supplementary Materials — PhD Thesis

This repository contains supplementary materials accompanying the PhD thesis of **Alessia Mapelli**, *Graphical models for the representation of complex biological systems: Linking molecular mechanisms to clinical phenotypes*.

## Contents

- **Supplementary_Tables_Ch6.xlsx**  
  Complete supplementary tables supporting Chapter 6, *Proteogenomic mapping to link plasma protein regulation and disease*.

- **Supplementary_Tables_Ch7.xlsx**  
  Complete supplementary tables supporting Chapter 7, *Genetically anchored multilayer networks for multi-omics and clinical data integration*.

- **`multilayer-network-viz.html`**  
  Interactive visualisation of the genomically anchored multilayer network developed in Chapter 7.

- **`edges_multi_layer_graph.csv`**  
  Edge list for the Chapter 7 multilayer network, including within- and cross-layer relationships and associated annotations.

- **`nodes_multi_layer_graph.csv`**  
  Node-level information for the Chapter 7 multilayer network, including biological layer, entity type, and community assignment.

## Usage

The Excel files provide the complete machine-readable supplementary tables referenced in the corresponding thesis chapters. The `multilayer-network-viz.html` can be opened in a web browser for interactive exploration. The CSV files provide the node and edge data to be uploaded to the web application.
